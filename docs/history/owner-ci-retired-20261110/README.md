# PR·원격 CI 운영 보존 구역

2026-11-10 Owner의 #905 최종 결정으로 대체된 운영 정책의 전체 원문이다. 기존 PR·Run/Attempt·태그·digest·FAIL/미검증 이력을 지우거나 새 소스의 PASS로 사용하지 않는다. 이 구역의 PR·CI·Trusted·Finalizer 요구는 신규 작업의 지침이 아니다. 원래 경로와 원본 SHA256은 `ORIGINALS.json`에 기록했다. 현재 단계와 완료 조건은 [Issue Lifecycle](../../ISSUE_LIFECYCLE.md)을 따른다.

추가 부분 보존인 [SECURITY 공급망 절](SECURITY_SUPPLY_CHAIN.md)은 해당 파일에 baseline·원본 파일/문단 SHA256과 범위를 명시했다. 인증·데이터 보안 계약 전체를 과거 지침으로 분류한 것이 아니다.
