## 설계 기준
1. 기존 SQLite migration은 수정하지 않고 `0002_task_details.sql`로 확장한다.
2. Description은 최대 4,000자, URL은 최대 2,048자이며 `http`/`https`만 허용한다.
3. 진행률은 0~100 정수 슬라이더로 편집한다.
4. 기존 일정/Revision/편집 세션 규약을 유지한다.
5. `main`이 이미 `0.7.0`이므로 이번 기능 추가는 Semantic Versioning의 다음 MINOR인 `0.8.0`으로 관리한다.
6. 프로젝트 복사는 단일 transaction으로 처리하고 원본 ID를 재사용하지 않는다.
