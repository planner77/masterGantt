# Issues #27, #33, #35, #36, #37 구현·검증 기록

## 릴리스 기준

기준 `main`은 `0.7.0`이며 이번 변경은 하위 호환 사용자 기능/API 추가이므로 Semantic Versioning의 MINOR 증가인 **0.8.0**으로 관리한다. `package.json`과 `package-lock.json`의 top-level/root version을 모두 `0.8.0`으로 일치시킨다.

## 이슈별 Acceptance Criteria 재검증

### #27 프로젝트 복사
- 프로젝트 목록과 상세 화면에 `프로젝트 복사` 진입점을 둔다.
- 원본의 유효한 edit session과 exact Origin, strong `If-Match`를 요구한다. 목록에서는 session이 없을 때 기존 잠금 해제 API로 원본 비밀번호를 검증한다.
- `POST /api/projects/{sourcePublicId}/copy`는 bounded/strict JSON과 기존 프로젝트 생성 rate limit/KDF 제한을 적용한다.
- password hashing은 write transaction 전에 수행하고, IMMEDIATE transaction 안에서 session binding/authVersion/expiry와 source revision을 다시 검증한다.
- Project/Task/Link/Holiday/새 edit session을 한 transaction에서 복사하며 중간 실패는 전체 rollback한다.
- Project/Task/Link public/internal ID는 새로 발급하고 Task externalId는 프로젝트 범위 식별자로 유지한다. parent/link endpoint는 새 Task PK로 재연결한다.
- 기본은 날짜·진척률 보존이다. `resetProgress=true`는 leaf/milestone을 0으로 만들고 summary를 기존 집계 규칙으로 재산출한다.
- 성공은 201, Location, ETag `"1"`, 새 프로젝트 edit-session Cookie와 canonical snapshot/counts를 반환한다.

### #33 Gantt 데모 메뉴 제거
- 상단 주요 메뉴에는 `프로젝트`만 남기고 `Gantt 데모` 링크를 노출하지 않는다.
- `/gantt-demo` 개발용 route 자체의 제거는 이 이슈의 메뉴 제거 수용 기준과 분리한다.

### #35 Chart 일/주 표시 단위 전환
- Chart 위에 `일`/`주` 토글을 제공하고 기본값은 `일`이다.
- `일`: month/day scale, `주`: month/week scale을 사용한다.
- SVAR React Gantt 2.7의 공식 `scales` API에서 지원하는 `day`/`week` unit을 사용하며 데이터/일정 계산은 변경하지 않는다.

### #36 Task Editor 확장
- 진행률은 0~100 정수 range slider로 편집한다.
- Description은 여러 줄, 최대 4,000자다.
- URL은 최대 2,048자이며 `http`/`https`만 허용한다.
- `description`, `url`은 SQLite migration `0002_task_details.sql`에 저장되고 create/PATCH/canonical snapshot에서 round-trip한다.
- 기존 Task Editor의 dirty draft 폐기 확인, 412 conflict lock, explicit reload, focus 복귀 계약을 유지한다.
- URL이 저장된 작업을 일반 클릭하면 새 탭으로 URL을 연다. URL이 없는 작업은 기존 동작을 유지한다.

### #37 프로젝트 진입 시 편집 권한 재확인
- 프로젝트 snapshot 조회 뒤 `/edit-sessions/current`를 항상 조회한다.
- 권한 확인 중에는 unlock 입력/버튼을 잠근다.
- 유효 session이면 `편집 가능`, 없거나 실패하면 `읽기 전용`으로 표시한다.
- 클라이언트의 이전 상태만으로 편집 가능 여부를 결정하지 않는다.

## Codex P1/P2 리뷰 조치

- P1 작업 상세 mutation 누락: EnhancedProjectService가 기존 scheduler mutation과 동일 SQLite transaction 안에서 Description/URL을 저장하도록 보완.
- P1 canonical snapshot 상세 누락: DB TaskRecord를 기준으로 Description/URL을 canonical task DTO에 병합.
- P1 dirty draft 폐기: 기존 main Task Editor의 `변경사항 버리고 닫기/다시 불러오기` 흐름 복원.
- P2 412 recovery lock: `conflicted` 상태를 explicit reload 성공 전까지 유지.
- P1 URL activation: Gantt task click에서 저장된 http/https URL을 새 탭으로 실행.
- P1 #27 미구현: Copy API/service/repository/UI 흐름 구현.
- P1 #35 미구현: 일/주 scale control 구현.
- P1 package-lock 불일치: package/lock 모두 0.8.0으로 동기화.
- P2 DB/API 문서 누락: `docs/API.md`, `docs/DB_SCHEMA.md`에 최종 계약을 반영했다.
