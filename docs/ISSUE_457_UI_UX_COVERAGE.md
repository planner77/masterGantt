## 측정과 provenance

[공통 helper](../tests/e2e/helpers/ui-geometry.ts)는 실제 표시되는 control과 populated table을 관찰한다. 닫힌 details·inert·aria-hidden 표면, 숨은 text node와 0폭/0높이 text range는 관측에서 제외한다. 입력값·비밀번호·세션·토큰을 수집하지 않는다. 최소 control/row/header 수를 먼저 확인하므로 빈 배열이나 colspan empty row가 밀도·열 정렬 PASS의 근거가 되지 않는다.

목록의 `list-populated-1440` / `list-no-result-1440` 파일 key는 capture 별칭이다. 실제 JSON `facts.viewport`와 PNG1280×720이 검증 폭·높이의 기준이며1440px 실행으로 해석하지 않는다. 파일 이름과 원래 capture/test hash를 소급 변경하지 않는다.

각 current PNG와 동명의 JSON은 source SHA, `src/**` 전체 파일의 SHA256와 aggregate, 실행된 spec·공통 helper·설정·fixture의 SHA256, application version, actual viewport/height, locale/timezone/root font/DPR/visual viewport scale/browser, capture time, testcase·실행 명령·report를 연결한다. 초기 실행의 명령 별칭은 아래 실행 표의 실제 명령/원본 report로 해석한다. 이후 helper hash를 이전 자료에 소급 적용하지 않는다.

normal은 정상 auth 상태를 뜻하며 비포커스 baseline을 뜻하지 않는다. Master의 기존 autofocus 때문에 normal-1440도 focused/focusVisible=true이며 Resource/Logistics 정상 자료는 false다. native Tab focus 자료와 실제 플래그를 구분한다.

Control은 border 네 면·색·배경·padding·font·실제 높이·label 연결·error description·disabled/readonly·native focus-visible 및 scroll clipping owner를 수집한다. 인증 입력의 label/border/background/padding, native keyboard outline과 실제 오류 description을 검사하고 sibling input/action의 비중첩을 확인한다. 같은 행 top/height 허용 오차는 1 CSS px이며 작은 화면 wrap은 별도 기대값이다. 기존 admin 40px, Task Editor 44px, nested Relation 자체 add 33.5px 예외를 동일 값으로 강제하지 않는다.

Document overflow는 `scrollWidth <= clientWidth + 1`이다. 내부 table/Gantt scroll은 별도로 기록한다. Populated table의 header/body 열 경계 및 표시 text의 cell 침범을 검사하고 의도된 ellipsis/clip은 구분한다. row height min/max, viewport와 owner에 교차하는 row 수, usable width/height, 편집 control 수를 기록한다. 가상화 Gantt의 DOM row 수를 전체 Task 수로 보고하지 않는다.

## Issue #502 후속 자동화 경계

#502는 #457의 미실행 항목 중 실제 React route error boundary만 자동화한다. 하니스는 `NODE_ENV !== "production"`이고 `E2E_ERROR_BOUNDARY_PROBE=true`인 Playwright webServer에서만 활성화한다.
