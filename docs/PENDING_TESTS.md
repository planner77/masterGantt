- [ ] Grid Header `+` 및 기존 Summary 행 `+`는 입력창 없이 즉시 생성하며 name이 정확히 `새 작업`인지 확인.

- [ ] 생성 요청의 `start`는 제출 시 브라우저 local 오늘, 일반 Task의 `duration`은 1인지 확인. 날짜 입력을 사용하던 기존 E2E는 요청 payload와 저장 snapshot 검증으로 갱신.

- [ ] 오늘이 토·일 또는 휴일이면 Auto 일정이 다음 근무일로 조정되고 사용자 안내가 유지되는지 확인.
- [ ] 최초 하위 추가의 Summary 전환 확인·취소, 기존 Summary 하위 추가, Milestone 부모 거부와 조상 집계가 유지되는지 확인.
