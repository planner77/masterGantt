## 별도 실행할 작업

### Grid Header 우클릭 열 선택

- [ ] 초기 외부 ID는 숨김, 작업·시작·기간은 표시되며 기존 외부 ID 표시/숨기기 버튼과 toolbar 여백이 없는지 확인.
- [ ] Grid Column Header 우클릭에서만 표시 열 선택 메뉴가 열리고 Chart header/작업 행의 우클릭은 가로채지 않는지 확인.
- [ ] 작업·외부 ID·시작·기간의 표시/숨김이 Grid에 즉시 적용되고 마지막 데이터 열은 숨길 수 없는지 확인. `+`는 권한에 따른 고정 action으로 유지.
- [ ] 외부 ID를 표시한 뒤 다른 열 제목에서도 다시 숨길 수 있고 모든 메뉴 항목의 체크 상태가 실제 열 상태와 일치하는지 확인.
- [ ] 읽기 전용에서도 열 선택이 가능하며 API 변경 요청을 발생시키지 않는지 확인.
- [ ] 저장·오류 복원·편집 모드 전환으로 Gantt가 remount돼도 같은 workspace의 선택 상태가 유지되는지 확인. 페이지 새로고침은 기본값으로 초기화하는 정책 확인.
- [ ] Escape/바깥 클릭/스크롤로 메뉴가 닫히고 포커스가 복귀하는지, Shift+F10/ContextMenu 키와 키보드 항목 선택이 가능한지 확인.
- [ ] viewport 하단·우측 및 좁은 화면에서도 메뉴가 잘리지 않는지 확인. 헤더 정렬·열 리사이즈·Grid/Chart 동기 스크롤 회귀 확인.
- [ ] 기존 `project-workspace-layout.spec.ts`의 외부 ID 버튼 테스트를 우클릭 메뉴 및 기본 숨김 계약으로 갱신하고 브라우저 검증을 수행.
