# masterGantt v0.13.0

Issue #28의 Excel Grid/Gantt 내보내기 기능을 추가하는 하위 호환 MINOR 버전이다.

## 주요 변경

- 프로젝트 화면에서 Excel(`.xlsx`) 내보내기 진입점 제공
- Grid와 Gantt timeline을 동일 작업 행으로 표현하고 WBS/계층, 시작·종료일, 근무일 기간, 진행률 보존
- 매 실행 시 작업 관계 `포함 / 제외 / 취소`를 명시적으로 선택
- 관계 포함 시 `Dependencies` 시트와 Gantt DrawingML 연결 화살표 생성
- 관계 제외 시 관계 시트·열·Drawing relationship을 생성하지 않음
- canonical Project snapshot과 strong `If-Match`를 사용하여 사용자가 확인한 revision의 읽기 전용 데이터만 출력
- SVAR PRO export 및 외부 Excel SaaS를 사용하지 않고 Node 표준 기능 기반의 내부 OOXML/XLSX writer 사용
- 사용자 문자열은 수식이 아닌 문자열 셀로 기록하고 매크로·외부 데이터 연결을 생성하지 않음

## 버전 정책

사용자에게 노출되는 신규 기능이므로 Semantic Versioning의 MINOR 변경으로 분류하여 `0.12.0`에서 `0.13.0`으로 증가한다. `package.json`과 `package-lock.json`은 동일한 `0.13.0`으로 유지한다.

## 검증

PR #55의 최종 head에서 GitHub Actions `quality`, Chromium E2E, Docker/runtime smoke를 검증한다. 최종 PASS 여부는 실제 해당 head의 CI 결과를 기준으로 판정한다.

Windows Excel 2021 및 조직 DRM 환경에서의 실제 열기·표시 검증은 GitHub-hosted runner가 대체하지 않으며 별도 Environment-specific Validation 대상으로 유지한다.
