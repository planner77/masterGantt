# masterGantt v0.16.0

Issue #57의 작업 캘린더 관리 기능을 추가하는 하위 호환 MINOR 버전이다.

## 주요 변경

- Project 작업 캘린더를 `Base weekly rule + WORKING/NON_WORKING date exception` 모델로 일반화
- KR/CN/VN/PH/TH/MX/US 7개 국가의 검증된 2026 fixture와 source/version metadata 추가
- Project 전체 또는 기간 지정 국가 공휴일 rule 지원
- Project/Resource Group/Resource Custom 휴무일 지원
- 중국·베트남의 공식 보충/교환 근무일을 `WORKING` override로 표현
- Calendar Preview에서 변경 Task와 Manual conflict 확인
- Calendar 저장을 edit session + Origin + If-Match + 단일 SQLite transaction으로 처리
- `0006_work_calendars.sql`에서 기존 `project_holidays`를 손실 없이 신규 rule/date 모델로 이관
- 기존 `project_holidays` 접근은 호환 VIEW/INSERT trigger로 유지
- #56 Resource workload를 Project + Group + Resource Effective Calendar와 연결
- Project 설정 modal에 작업 캘린더 편집/Preview UI 추가
- SVAR PRO Calendar/API를 사용하거나 복제하지 않고 기존 pure Scheduling Domain을 확장

## 버전 정책

사용자에게 노출되는 신규 Calendar 관리 기능과 신규 API/DB schema가 추가되므로 Semantic Versioning MINOR 변경으로 `0.15.0`에서 `0.16.0`으로 증가한다. `package.json`과 `package-lock.json`의 version은 `0.16.0`으로 일치한다.

## 데이터 호환

- 기존 Project의 수동 holiday는 migration 0006에서 `CUSTOM / PROJECT / NON_WORKING` rule/date로 보존한다.
- migration만으로 기존 Project에 국가 공휴일을 추가하지 않아 기존 일정을 조용히 변경하지 않는다.
- 신규 Project는 2026 KR/FULL_PROJECT rule을 기본 materialize한다.
- 국가 fixture가 없는 연도는 추정하지 않고 `COUNTRY_CALENDAR_UNAVAILABLE`로 거부한다.
