# v0.23.2 — Issue #108 Excel 주차 헤더 표시 수정

## 변경 내용

Excel 내보내기 `Gantt` 시트의 주차 헤더에서 연도와 `W` 접두어를 제거한다.

- 변경 전: `2026-W39`
- 변경 후: `39`

월 헤더의 `YYYY-MM` 표시는 유지한다. ISO week 계산 규칙과 연말/연초 grouping key는 변경하지 않으므로 `2026-12-31`과 `2027-01-01`은 기존과 동일하게 `2026-W53`에 속하고 표시만 `53`이 된다.

## 호환성

API, DB schema, Project revision, Gantt 데이터, 스타일, 병합 범위, 다른 Excel sheet 계약은 변경하지 않는다. 기존 표시 결함 수정이므로 `0.23.1 → 0.23.2` PATCH release다.
