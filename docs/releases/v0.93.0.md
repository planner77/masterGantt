# v0.93.0 — Issue #342 국가 Calendar Catalog

## 범위

- KR/CN/VN/PH/TH/MX/US의 국가 Calendar 관리 연도를 2026~2037로 정의한다.
- 2026 built-in fixture + DB override 구조를 도입한다.
- 공식 자료가 없는 미래 연도는 UNAVAILABLE로 유지하고 추정하지 않는다.
- JSON/CSV Import Preview/Apply와 국가·연도별 날짜/metadata CRUD를 제공한다.
- Project Calendar Preview/Save와 신규 Project 기본 Calendar가 최신 OFFICIAL dataset을 사용하도록 한다.

## 호환성
