## Review rework

- Manual date CRUD invalidates OFFICIAL provenance and requires metadata reapproval before Scheduling reuse.
- Country Calendar persistence is routed through a dedicated Repository.
- File import selection ignores stale asynchronous reads from previously selected files.

- Target/snapshot consistency is fail-closed on country/year load failure, and 412 reload discards stale date-edit drafts.
- Date PATCH rejects empty/unknown payloads; deleting the sole date is allowed because manual mutations invalidate the dataset before Scheduling reuse.
- Successful Import Apply resets the native file input so the same file can be selected again.

- Countries with no effective OFFICIAL year return nullable source provenance instead of falling back to superseded built-in metadata.

## Review rework 4

- Import Apply requires an HMAC-bound token returned by Preview for the exact catalog revision, target and file bytes.
- Unchanged manual edits are no-ops; target switches clear create/file drafts; delete cancel is disabled while pending.
- New project creation remains available during KR override reapproval by falling back to the built-in approved default baseline.

## Review rework 5

- No-op metadata/date edits preserve revision and approved provenance.
- Explicit null date patch values are rejected instead of treated as omission.
- Session expiry discards stale edit/delete drafts; pending dialogs cannot be cancelled while mutations continue.
- Delete success restores focus to a surviving dates section when the original row trigger is gone.
- Country/year switching defers reload to the next task so native select interaction completes deterministically.
