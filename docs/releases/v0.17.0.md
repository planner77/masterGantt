# masterGantt v0.17.0

Issue #68의 작업 캘린더 변경 시 FS/lag=0 Dependency 재계산을 추가하는 하위 호환 MINOR 버전이다.

## 주요 변경

- 후보 Calendar에서 Leaf base 일정을 계산한 뒤 저장된 FS/lag=0 Dependency를 DAG forward-pass로 적용
- Auto 후행 Task의 dependency 이동과 실제 lower-bound 선행 External ID를 Calendar Preview에 표시
- Manual Calendar conflict와 Manual Dependency conflict를 구분하고 저장 전체를 원자적으로 거부
- 최종 Leaf 결과에서 Summary를 재집계
- broad `CALENDAR_RECALC_UNSUPPORTED` 대신 cycle/지원 외 구조를 구조화된 오류로 분리

## 저장 계약

Calendar rule/date 교체, Auto Task/Summary 일정 갱신, Project revision +1은 하나의 SQLite `BEGIN IMMEDIATE` transaction에서 처리한다. Preview는 저장하지 않는다.

## 검증

작업 브랜치에서는 Domain/Service 회귀 테스트를 추가한다. 최종 release 판정은 PR의 GitHub Actions quality, Chromium E2E, Docker smoke를 모두 통과한 뒤 수행한다.
