# masterGantt v0.12.0

Issue #19 글로벌 리소스·리소스 그룹 및 작업 직접 할당 기능을 추가한 하위 호환 MINOR 릴리스다.

## 주요 변경

- Project와 독립된 글로벌 Resource / Resource Group 카탈로그와 `/resources` 관리 화면
- Project 편집 권한과 분리된 Resource catalog 관리자 세션 (`RESOURCE_CATALOG_ADMIN_PASSWORD`)
- Group 멤버 관리, 활성/비활성 상태, catalog revision 기반 optimistic concurrency
- Task / Summary / Milestone에 Resource 또는 Group 복수 직접 할당·해제
- Group 할당은 담당 팀 참조이며 Group member 개인 할당으로 자동 확장하지 않음
- Assignment PUT 응답을 최신 `project`, `tasks`, `links`, `assignments` canonical aggregate와 strong Project ETag로 통일
- SQLite `0003_resource_catalog.sql` migration 추가
- SVAR React Gantt PRO Resource API/package는 사용하지 않고 앱 자체 DB/API/UI 경계로 구현

## 운영 전 확인

- 기존 DB는 애플리케이션 시작 또는 `npm run db:migrate`에서 `0003_resource_catalog.sql`까지 순차 적용한다. 적용된 migration SQL은 수정하지 않는다.
- `RESOURCE_CATALOG_ADMIN_PASSWORD`는 Project 편집 비밀번호와 별도이며 최소 16자 이상으로 운영 secret에서 주입한다. 미설정/16자 미만이면 관리자 인증은 fail-closed 된다.
- 기존 Project/Task 데이터는 유지되며 신규 global catalog와 assignment는 초기 상태가 비어 있다.
